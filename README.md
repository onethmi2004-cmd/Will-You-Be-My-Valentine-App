💌 CantSayNo

A playful, interactive Valentine's Day web app built from scratch using up-to-date AI tools.

## About
This app asks the classic question — "Will you be my Valentine?" — but with a twist: 
the "No" button just won't let you say no.

## How It Works
- When the app opens, you're greeted with **"Will you be my Valentine?"** along with **Yes** and **No** buttons.
- Try clicking **No** — it playfully dodges away, making it impossible to say no!
- Click **Yes**, and a sweet message appears just for you.
- Want to go back? Click the **pen and ink** icon to return to the first page and try again.

## Features
- 🎯 Fun, animated "No" button that dodges your cursor/clicks
- 💖 Simple, romantic UI
- 🔄 Seamless navigation between screens

## Built With
- HTML
- CSS
- Java Script
